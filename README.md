# Проект: Гео Поиск

Поисковик улиц на основе ГИС данных. В проекте используется единственный API метод для поиска улиц в заданном городе.

## API Метод
- **Метод**: `POST`
- **Путь**: `/api/v1/highway/find/`

Тестовый город Ярославль находится в папке `backup`. Вы можете заменить его данными других городов.

## Шаги для запуска проекта

### 1. Запуск контейнеров
Для запуска всех необходимых контейнеров используйте следующую команду:

```bash
docker-compose up -d
```
Эта команда запустит базу данных (postgres) и геопоиск (geosearch).

### 2. Убедитесь, что PostGIS активирован
Перед восстановлением базы данных проверьте, что расширение PostGIS установлено и активировано. Для этого выполните следующие шаги:

Войдите в контейнер базы данных:
```docker exec -it postgres bash```
Скачайте postgis
```apt-get install postgis```
Подключитесь к базе данных:
```psql -U postgres -d postgres```
Проверьте наличие PostGIS:
```SELECT postgis_full_version();```
Если расширение не установлено, активируйте его:
```CREATE EXTENSION postgis;```
### 3. Восстановление базы данных
Чтобы восстановить базу данных из бекапа, выполните следующие шаги:

Скопируйте файл бекапа yaroslavl.sql в контейнер базы данных:
```docker cp /path/to/yaroslavl.sql postgres:/backup/```
Войдите в контейнер базы данных:
```docker exec -it postgres bash```
Выполните команду восстановления базы данных:
```pg_restore -U postgres -d postgres --no-owner --no-acl /backup/yaroslavl.sql```
### 4. Открытие интерфейса
После восстановления базы данных откройте файл `find.html` в браузере.
